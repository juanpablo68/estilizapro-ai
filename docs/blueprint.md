# **App Name**: EstilizaPro AI

## Core Features:

- Secure Local Profile Access: Allow users to log in with a generic local passcode ('1,2,3,4') to ensure isolated access and local storage of their personal data within the web application.
- Personal Style Questionnaire: Capture the user's specific fashion tastes, preferences, and lifestyle through an interactive form to inform personalized styling decisions.
- Stylized Avatar Creation Tool: Enable users to upload photos of their face and figure to generate a unique, Pixar-like animated avatar using an AI tool for personal visual representation.
- Virtual Wardrobe Manager: Provide functionalities to photograph, upload, and organize images of physical clothing items, storing them locally on the device for future reference and styling.
- AI-Powered Capsule Recommendations: Generate personalized outfit 'capsules' based on user data, including an AI tool for colorimetry and figure analysis, preferences, event type, and weather, suggesting both personal wardrobe items and complementary shop items.
- AI Stylist Chat Assistant: Offer an AI chatbot that behaves as an expert image consultant, identifying itself as 'asistente de Pilar Cifuentes Catalán,' to answer fashion queries and provide styling advice.
- Avatar Outfit Preview Tool: Utilize an AI tool to dynamically visualize how specific clothing items from the user's virtual wardrobe would appear on their generated stylized avatar.
- API & Knowledge Management for AI: A dedicated section within the menu to write necessary APIs and load knowledge for the AI models.
- Additional Capsule Purchase: Allow users to purchase additional capsules for $3, which are then stored on the device for future use. Includes contact information for personalized styling.

## Style Guidelines:

- Primary color: Dominant Pink (#FF69B4) for a vibrant, fashionable, and personalized styling experience, reflecting creativity and modern elegance.
- Background color: A subtly warm and highly desaturated lavender-grey (#F2F0F5) to create a clean, minimalist canvas that allows content and primary elements to stand out without distraction.
- Accent color: Deep Ocean Blue (#292999). This rich, contrasting blue provides emphasis for interactive elements and key information, lending a professional yet engaging feel.
- Headline font: 'Playfair Display' (serif) to convey an elegant, fashionable, and high-end aesthetic. Body font: 'PT Sans' (sans-serif) for its modern look and excellent readability in longer text blocks like styling advice or chat conversations.
- Use sleek, minimalist line icons with a refined contemporary style. Icons should be clear, intuitive, and complement the sophisticated color palette.
- Adopt a responsive, mobile-first layout with clean lines, ample white space, and clear content hierarchies. Emphasize card-based layouts for wardrobe items and capsules to ensure visual distinction and easy navigation on smaller screens.
- Implement subtle, smooth transitions and micro-animations, particularly during avatar generation, outfit previews, and content loading, to enhance user engagement and provide a fluid experience.
